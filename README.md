# Hands-On Data Lab Implementation

This project demonstrates a basic data-science workflow using Python, Pandas, NumPy, Matplotlib, and Seaborn.

## Objectives covered
1. Set up a Python data-science environment.
2. Load and manipulate data with Pandas and NumPy.
3. Clean missing values, duplicate rows, and data types.
4. Create bar, line, histogram, scatter, and box plots.
5. Calculate descriptive statistics and correlations.
6. Document the code, outputs, and observations in a Jupyter Notebook.

## Folder structure
- `data/student_performance.csv` — sample dataset
- `data_lab.ipynb` — complete notebook with exercises and explanations
- `data_lab.py` — runnable Python script version
- `requirements.txt` — required Python packages
- `outputs/` — generated charts are saved here when the script runs

## Run on a laptop
1. Install Python 3.10+ from https://www.python.org/downloads/
2. Open a terminal in this project folder.
3. Install dependencies:
   ```bash
   python -m pip install -r requirements.txt
   ```
4. Run the script:
   ```bash
   python data_lab.py
   ```
5. Or launch Jupyter:
   ```bash
   jupyter notebook data_lab.ipynb
   ```
