# Report guide and evidence checklist

## Suggested report title
Hands-On Data Lab Implementation using Python

## Objective
To configure a basic Data Science environment and apply Python libraries to practical data manipulation, cleaning, visualization and statistical analysis.

## Work performed
1. Loaded and inspected a synthetic CSV dataset using Pandas.
2. Checked missing values and duplicate records.
3. Removed duplicate rows, converted numeric fields, and filled missing numeric values using column medians.
4. Created an average score and a performance category.
5. Used descriptive statistics and group-wise aggregation.
6. Created five charts: score distribution, performance-level comparison, study-hours scatter plot, correlation heatmap and subject average comparison.

## Evidence to attach
- Screenshot of VS Code showing `py main.py` and the completion message.
- Screenshot of the `outputs` folder showing the generated CSV, TXT and PNG files.
- Insert the five generated charts in the report with one or two sentences describing each.
- Include the GitHub repository URL after you push the complete project.

## Integrity
The dataset is synthetic practice data. Explain that it is used to demonstrate the workflow; do not claim it came from a school or university.
